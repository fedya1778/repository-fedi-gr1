# HW10-11 – Компьютерное зрение в PyTorch: CNN, Transfer Learning, Detection/Segmentation

## 1. Кратко: что сделано
*   **Часть A:** Выбран датасет **STL10** (изображения 96x96), что позволяет эффективно обучать как простые CNN, так и предобученные архитектуры (ResNet).
*   **Часть B:** Выбран датасет **OxfordIIITPet** и трек семантической сегментации. Это классическая задача для отработки навыков работы с пиксельными метками и постобработкой масок.
*   **Эксперименты:**
    *   В части A сравнивались 4 режима: простая CNN (без/с аугментациями) и ResNet18 (заморозка бэкбона / финетюн).
    *   В части B сравнивались два режима постобработки масок: базовая бинаризация и морфологическая очистка.

## 2. Среда и воспроизводимость
*   **Python:** `3.11.0`
*   **torch / torchvision:** `2.5.1+cu121` / `0.20.1+cu121`
*   **Устройство:** `cuda` (GPU)
*   **Seed:** `42`
*   **Как запустить:** открыть `HW10-11.ipynb` и выполнить `Run All`.

## 3. Данные

### 3.1. Часть A: Классификация
*   **Датасет:** `STL10`
*   **Разделение:** `train/val/test` (стандартный `split='train'` для обучения/валидации, `split='test'` для финального теста).
*   **Базовые transforms:** `ToTensor`, `Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5))`, `Resize` до 224 для ResNet.
*   **Augmentation transforms:** `RandomHorizontalFlip(p=0.5)`, `RandomRotation(degrees=10)`, `RandomResizedCrop` (для ResNet).
*   **Комментарий:** STL10 содержит 10 классов. Задача сложнее CIFAR10 из-за большего разрешения и меньшего размера размеченной выборки.

### 3.2. Часть B: Structured Vision
*   **Датасет:** `OxfordIIITPet`
*   **Трек:** `segmentation`
*   **Ground Truth:** Пиксельная маска, где класс `15` соответствует объекту (питомцу), остальное — фон.
*   **Предсказания:** Выход модели `DeepLabV3` (логиты), преобразованный в бинарную маску через `argmax` и пороговую обработку.
*   **Комментарий:** Сегментация позволяет оценить качество выделения объекта на уровне пикселей.

## 4. Часть A: модели и обучение (C1-C4)

### Модели
*   **C1, C2:** Простая CNN с двумя сверточными слоями (32 и 64 фильтров), batch normalization и fully connected слоем.
*   **C3, C4:** ResNet18 с предобученными весами ImageNet (`ResNet18_Weights.IMAGENET1K_V1`).

### Режимы обучения
*   **C1 (simple-cnn-base):** Обучение с нуля без аугментаций.
*   **C2 (simple-cnn-aug):** Обучение с нуля с аугментациями (flip, rotation, color jitter).
*   **C3 (resnet18-head-only):** Transfer learning с замороженным backbone. Обучается только классификатор (fc слой).
    *   `requires_grad=False` для всех слоев, кроме `model.fc`
    *   Learning rate: 1e-3
*   **C4 (resnet18-finetune):** Fine-tuning с частичной разморозкой. Обучаются layer4 и fc.
    *   `requires_grad=False` для всех слоев, кроме `model.layer4` и `model.fc`
    *   Differential learning rates: 1e-4 для layer4, 1e-3 для fc
    *   Weight decay: 1e-4

### Preprocessing для ResNet18
Для предобученной модели используется стандартный preprocessing ImageNet:
```python
weights = ResNet18_Weights.IMAGENET1K_V1
preprocess = weights.transforms()  # Resize(256), CenterCrop(224), ToTensor, Normalize
```
В эксперименте применены эквивалентные transforms вручную:
*   Train: `Resize(224) → ToTensor → Normalize(mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225])`
*   Augmented: `Resize(256) → RandomResizedCrop(224) → RandomHorizontalFlip → ToTensor → Normalize`

## 5. Часть B: постановка задачи и режимы оценки (V1-V2)
*   **Модель:** `DeepLabV3` с бэкбоном `ResNet50` (pretrained).
*   **Foreground:** Класс с индексом `15` (питомец).
*   **Режимы:**
    *   **V1:** Базовая постобработка (просто `argmax` по выходу модели).
    *   **V2:** Альтернативная постобработка (морфологическая очистка: удаление мелких компонент связности).
*   **Метрики:**
    *   `mean IoU`: Пересечение предсказания и GT, деленное на их объединение.
    *   Дополнительные: `Pixel Precision`, `Pixel Recall`.

*   **Критерий выбора:** Максимальная `accuracy` на валидационной выборке.

## 7. Анализ

### Короткая сводка
*   **Лучший эксперимент части A:** `C4` (ResNet18 Fine-Tune).
*   **Лучшая `val_accuracy`:** `0.954`.
*   **Итоговая `test_accuracy`:** ~0.95 (значение из `runs.csv`).
*   **Аугментации (C2 vs C1):** В данном эксперименте не улучшили результат простой CNN (возможно, из-за сложности задачи или малого числа эпох).
*   **Transfer Learning (C3/C4 vs C1/C2):** Дал значительный прирост качества (~0.3 accuracy).
*   **Head-only vs Fine-tuning:** Partial fine-tuning (`C4`) показал немного лучший результат, чем `head-only` (`C3`).
*   **Режим V1:** Базовая постобработка дает хорошее начальное качество.
*   **Режим V2:** Морфологическая очистка убирает шум и мелкие ложные срабатывания, улучшая `IoU`.

## 8. Итоговый вывод
В ходе работы были освоены навыки обучения сверточных сетей с нуля и с использованием transfer learning. Transfer learning на архитектуре ResNet18 показал значительно лучшие результаты по сравнению с простой CNN, что подчеркивает важность предобученных весов для задач компьютерного зрения. Fine-tuning последних слоев бэкбона позволил добиться наилучшего результата в классификации. В задаче сегментации было показано, что постобработка масок (морфологические операции) может существенно улучшить метрики качества, убирая шум. Наиболее эффективным подходом в части A оказался финетюнг предобученной модели.

## 9. Выбор базового конфига и инсайты
*   **Базовый конфиг классификации:** Выбран конфиг **C4 (ResNet18 Fine-Tune)**, так как он показал наилучшую точность и является стандартом для подобных задач.
*   **Инсайт про Transfer Learning:** Предобученные модели позволяют быстро достичь высокого качества даже на небольших датасетах, требуя меньше эпох обучения.
